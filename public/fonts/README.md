# Fonts — Vice City Stories

Self-hosted, no runtime dependency on Google Fonts or any external font CDN.

## Bebas Neue

- File: `bebas-neue-latin.woff2` (static, weight 400)
- Designer: Dharma Type
- License: **SIL Open Font License, Version 1.1**
- Source: Google Fonts (`fonts/bebasneue`), OFL text:
  https://github.com/google/fonts/blob/main/ofl/bebasneue/OFL.txt
- Used for: display headings, menu title, panel titles.

## Inter

- File: `inter-latin.woff2` (variable font, weight axis 100–900)
- Designer: The Inter Project Authors (Rasmus Andersson)
- License: **SIL Open Font License, Version 1.1**
- Source: Google Fonts (`fonts/inter`), OFL text:
  https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt
- Used for: UI and body text.

Both licences permit redistribution, modification and commercial use.
Do not replace these files with a CDN link — the game must render its
typography offline.
